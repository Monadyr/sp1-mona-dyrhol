# Community Science Museum

## Description
This is a multi-page website for the Community Science Museum, designed to engage children aged 7-15 years and families with young children. The website enusure easy access to information through a clear and consistent navigation menu. 

## Live website
https://monadyr.github.io/sp1-mona-dyrhol/

## Workflow
This project mainly uses a simple Git workflow.

### Branch usage:
- The main branch contains the final and stable version of the project.
- A single additional branch was used during development for creating navigation bar and footer.
Most development work was completed directly in main.

### Commit practice
Commit messages  were written to describe changes clearly.

### Note
This project does not use a full multi-branch workflow, as it is a individual development process.

## Development
- HTML5
- CSS
- Flexbox and CSS Grid

The website is tested using Lighthouse and WAVE to evaluate performance and accessibility.
